### the short version

i build backends in **Go**, run **[Rai Computer](https://raicomputer.com)** — a 12+ year old doorstep IT & AMC business in Mumbai — and spend suspicious amounts of time drilling into things most people abstract away (red-black trees, syscalls, CPU pipelines, the works).

my learning mode is *go-until-you-hit-the-transistor*. my coding mode is *idiomatic Go, no ceremony, no enterprise cosplay*.
